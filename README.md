## 先把三个词分开：双栈、双ISP、原生IP

「双栈VPS」和「双ISP VPS」只差一个字，搜错的人不少。丽萨主机自己的德国产品线就是把这两类拆开卖的，正好拿来当例子。

**双栈（Dual Stack）**：网络层面的事。一台服务器同时持有可用的IPv4和IPv6地址，访问方用哪种协议连都行。它只说明「两种协议都通」，跟IP属于机房还是家庭宽带没有任何关系。

**双ISP**：IP注册属性层面的事。一个IP同时注册在两家本土运营商名下，纯净度更高，被平台判定为真实家庭用户的概率更大。丽萨主机德国住宅线的描述是「IP归属德国本地宽带运营商，type为isp/isp」。

**原生IP**：归属地真实，但仍然是机房分配的地址段，type显示为datacenter。它解决了「IP注册地是不是德国」的问题，没解决「像不像家庭用户」的问题。

## IPv6 到底怎么拿到

这是「双栈」两个字最容易被误解的地方。默认给的是1个IPv4，IPv6不是开通即到手的。

- **德国9929线**：免费送5个IPv6地址，购买后提交工单配置。
- **其他节点**：美国西雅图、日本、新加坡、英国等节点已支持IPv6，同样通过工单免费申请；官方计划后续覆盖美国纽约和芝加哥。关于香港和台湾节点的IPv6状态，两处公开表述不一致，一处写香港、一处写台湾，要买这两个节点的话直接开工单问清楚。
- **资料没披露的**：IPv6前缀大小（是不是/64）、是否静态、能否追加更多、IPv6回程走什么线路、国内IPv6网络直连质量如何。这几项决定了你拿到的IPv6能不能真正当主力地址用，建议下单前一次性问完。

换句话说，丽萨主机的「双栈」准确表述是：**IPv4默认交付，IPv6免费但需工单开通**。这不影响它作为双栈方案使用，但如果你指望开机就双栈、脚本一跑就拿到v6地址，会多一个提工单的步骤。

**双栈和双ISP到底哪个是我要的？**
看你要解决什么问题。要让机器同时响应IPv4和IPv6请求（比如跑支持v6的爬虫、给网站加AAAA记录、测试IPv6回程），选双栈。要让平台认为你是德国本地家庭用户，选双ISP住宅。前者68元起，后者169元起，差价买的是IP属性，不是配置。

不用。德国9929线免费给5个IPv6，其他支持IPv6的节点也是工单免费申请。成本是你的时间，不是钱。

**能装Windows吗？**
官方产品页标注支持安装Windows。具体镜像版本和授权方式，下单前问客服确认。
